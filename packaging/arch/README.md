# Arch packaging layout

This repository keeps two PKGBUILDs because they have different source inputs:

| Path | Use | Source | Checksum |
| --- | --- | --- | --- |
| `local/PKGBUILD` | `make build` from the working tree | generated local archive | injected temporarily by the build script |
| `ci/PKGBUILD` | tagged release | GitHub tag archive | generated by `updpkgsums` in CI |

Both PKGBUILDs share metadata and portal payload behavior. Only their source
definitions differ. `common/functions.sh` normalizes the extracted source
directory from either `<repository>-v<version>` or `argvus-portal-<version>` to
the path expected by the package functions.

Generated checksums, `src/`, `pkg/`, archives, and packages are not committed.

Inspect metadata with:

```sh
makepkg -p packaging/arch/ci/PKGBUILD --printsrcinfo
makepkg -p packaging/arch/local/PKGBUILD --printsrcinfo
```
