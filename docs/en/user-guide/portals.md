---
title: Portals
description: Configure desktop portal selection for Hyprland.
---

`argvus-portal` installs the environment and portal selection files used by the XDG desktop portal stack. The Hyprland portal configuration is installed under `/usr/share/argvus/portal/config/xdg-desktop-portal/` in the package source and projected to the system configuration during packaging.

Portal behavior also depends on the installed `xdg-desktop-portal` backends and the active session environment.
