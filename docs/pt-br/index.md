`argvus-portal` instala arquivos de ambiente e seleção de portais para o stack XDG. A configuração Hyprland fica em `/usr/share/argvus/portal/config/xdg-desktop-portal/` na origem do pacote e é projetada para a configuração do sistema durante o empacotamento.
